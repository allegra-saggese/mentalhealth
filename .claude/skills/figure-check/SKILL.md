# Figure and Table Check

Standards live in `.claude/rules/figure-and-table-standards.md`. This skill measures what can be measured and looks at the rest.

## Steps

1. **Resolve targets.** A file, a folder (all `.png`/`.pdf`/`.tex` in it), or `latest` (newest dated exhibit per descriptor under `Data/output/figs` and `Data/output/tables`).
2. **Measure** with the helper (PNG pixel size and dpi, width in mm against 89 / 120 / 183 mm, matching vector PDF present, fonts embedded when `pdffonts` exists):
   ```bash
   python3 scripts/figure_check.py <files-or-folders>
   ```
3. **Look.** Read each image and check, item by item: panel labels; axis labels with units; legend; text legible at final size (5-7 pt); no in-figure title; colour-blind-safe and still readable in greyscale; confidence interval drawn **and stated** (level, estimator, fixed effects, clustering); event-study reference period marked, common y-axis, zero line; sample note (N counties, N county-years, window); source note naming the script that produced it; consistent estimator labels (TWFE vs Callaway-Sant'Anna).
4. **Tables (`.tex`).** `booktabs`, no vertical rules, SE in parentheses with the clustering stated, N / fixed effects / controls rows, no significance stars unless the venue profile says otherwise, generated by the shared table writer (not typed).
5. **Provenance.** The exhibit's script is named in its note; the result file it read is dated after the current panel (check the `MODEL-RUN-STATE` note).
6. **Report** (local, `quality_reports/figure_checks/YYYY-MM-DD_<descriptor>.md`): one line per item, PASS or FIX, the measured value, and the smallest change that fixes it. Mark passing exhibits as checked; failing ones stay DRAFT.

## Boundaries

- Read-only: the skill never edits a figure or script.
- A fix that changes what is plotted (sample, estimator, window) is a researcher decision and is listed separately from formatting fixes.
- A clean report says the exhibit meets the formatting standard; it does not say the result is right (that is `/audit-reproducibility`).
